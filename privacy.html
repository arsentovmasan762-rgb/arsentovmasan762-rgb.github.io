Data handling

Privacy policy

Effective 9 October 2026

DreamTouch Local Worker is a private Windows application operated by the owner of DreamTouch ASMR. This policy describes its read-only Google OAuth and YouTube analytics connection and this public information site.

Access and purpose

The owner personally authorizes Google access in Google's consent screen. The application requests only youtube.readonly and yt-analytics.readonly. It accesses the authorized channel's identity, channel statistics, video catalogue and metadata, publication and privacy information, and available aggregate Analytics and Reporting data.

Analytics can include views, watch time, average view duration and percentage, subscriber gains and losses, traffic sources, aggregate audience segments, retention curves, and thumbnail impressions and click-through rate when supported and available. These reports do not identify individual viewers. Missing metrics are not invented.

The data is used for private channel analysis, historical comparisons, evaluation of creative hypotheses and the owner's future creative decisions. It is not used to sell advertising, target individual viewers or provide a public analytics database.

Storage and security

OAuth access and refresh tokens are stored in an encrypted Windows Data Protection API (DPAPI) vault associated with the owner's Windows account. The OAuth client configuration is kept separately from the public site and outside the application's source repository. Google API requests use HTTPS.

Analytics responses, downloaded report files, derived observations and decision records are stored in local files and a local index, with local backup copies for recovery. Those analytical files are not individually encrypted by the token vault; their protection depends on the owner's Windows account, file permissions, device security and any disk encryption configured on that device. DPAPI is not a guarantee against malware or another process running as the owner.

Analytical records are currently retained for historical comparison. The existing application does not implement an automatic age-based purge. Revoking OAuth does not automatically erase files or backups already collected. The operator must keep API data refreshed or remove it where the applicable YouTube API retention rules require this.

Codex and off-device processing

The owner uses OpenAI Codex for requested analysis and creative reasoning. Selected analytics, derived observations and relevant analytical context can be included in Codex inputs and processed by OpenAI. Consequently, this application does not promise that all Google-derived data remains solely on the local computer.

OpenAI's handling and retention of that content depend on the applicable product, account terms and data controls. This policy does not assert that a particular provider retention or model-training setting has been verified for every account. The operator must use provider settings and agreements consistent with Google's applicable data-use restrictions. The worker itself does not train or fine-tune a general-purpose AI model.

OAuth client secrets, access tokens and refresh tokens are not included in analytical reports or intentionally supplied to Codex, the public website or its hosting repository. The application does not sell Google user data or transfer it to advertising platforms or data brokers.

Limited use

DreamTouch Local Worker's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Data provided for AI-assisted analysis is limited to delivering the owner's requested analytical and creative-planning features, with the owner's consent. This statement is not a claim that Google has audited or certified this application.

Revocation and deletion

You can revoke the application's access at Google Account connections. The application must not bypass revocation; subsequent API access requires a valid grant. Disconnecting the application does not delete existing YouTube videos or analytics held by Google.

To delete the local authorization and collected analytical data, the owner can remove the token vault, local analytical records and their backup copies. For assistance or a deletion request, contact arsent678@gmail.com. Data previously provided to OpenAI or Google is also governed by those providers' retention and deletion mechanisms.

This information website

This site contains public application information only. It has no Google sign-in, analytics dashboard, data collection form, advertising code or application tracking script. It is hosted on GitHub Pages. GitHub logs visitors' IP addresses for security purposes, even when they are not signed in; see the GitHub Privacy Statement. Visiting these pages does not connect a YouTube account.

External services and changes

The application uses YouTube API Services. See the Google Privacy Policy, YouTube Terms of Service and OpenAI Privacy Policy. These services have their own terms and data practices.

Material changes to Google data access, purpose or sharing will be disclosed before the changed use begins and will require consent where applicable. The effective date above identifies this version.
